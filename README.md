# fullpera-guide

フルペラフェス vol.1 の参加者向けガイドページです。GitHub Pages(main ブランチのルート)で公開しています。

## 中身は暗号化しています

`index.html` は、パスワードがないと読めない形に暗号化したものです。ページを開くとパスワードの入力画面が出て、正しいパスワードを入れたときだけ、ブラウザの中で元のページに戻ります。

- パスワードは、このリポジトリのどこにも書きません。全体グループLINEで共有します。
- 暗号化前の元ファイル(`source.html`)は、このリポジトリに入れません。
- 方式は AES-256-GCM、鍵はパスワードから PBKDF2-SHA256(60万回)で作ります。
- 「この端末では次から入力しない」にすると、その端末のブラウザに鍵が残ります。

## 更新のしかた

1. 元ファイルを編集し、「最終更新」の日付と「更新履歴」を直す
2. 暗号化する

   ```
   GUIDE_PASSWORD='パスワード' python3 tools/encrypt.py source.html index.html
   ```

3. `index.html` だけをコミットして、プルリクエストでマージする

`tools/salt.txt` は変えないでください。変えると、記憶済みの端末でも再入力が必要になります。参加者以外に知られたなど、全員に入れ直してもらいたいときは、パスワードを変えます。
